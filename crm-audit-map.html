Quick Wins para la Demo

Antes de mostrar

  • - Cargar datos reales en Supabase (al menos 10 clientes, 5 PR, 3 facturas)
  • - Verificar que el dashboard muestre datos reales, no mock
  • - Probar login con usuario admin y vendedor para mostrar filtro de sidebar
  • - Verificar que las alertas tengan contenido real

Durante la demo

  • - Mostrar flujo completo: crear cliente, crear PR, aprobar, generar remito
  • - Mostrar busqueda global (Cmd+K) con datos reales
  • - Mostrar el asistente IA generando un remito
  • - Mostrar cambio de rol (vendedor ve menos modulos)
  • - NO mostrar Configuracion en profundidad (mock)
  • - NO hacer click en "Exportar" de Reportes

Puntos fuertes para destacar

  • - 11 modulos funcionales con datos reales
  • - Asistente IA integrado (Claude)
  • - Sistema de roles con 5 niveles
  • - Doble moneda USD/ARS
  • - Busqueda global cross-modulo
  • - Dark mode
  • - Presupuestos con workflow completo de estados
